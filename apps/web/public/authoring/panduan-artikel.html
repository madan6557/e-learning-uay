Membuat artikel berbasis blok dengan bantuan AI

Kenali blok, format teks, dan cara membawa hasil AI ke editor materi. Panduan ini mengikuti format editor aplikasi per 29 September 2026.

Berkas ini dapat dibuka tanpa internet. Untuk menyimpan sebagai PDF, tekan Ctrl+P (atau menu Cetak browser), lalu pilih Simpan sebagai PDF.

1. Alur penggunaan

  1. Buka kelas dan Section, lalu tambah Materi teks atau edit materi yang sudah ada.
  2. Buka Panduan & artikel AI. Unduh prompt-artikel-ai.txt dan template-artikel.json.
  3. Isi topik, sasaran pembaca, tujuan, panjang artikel, dan sumber pada prompt. Kirim ke AI bersama contoh JSON bila diperlukan.
  4. Tempel JSON hasil AI atau pilih berkas .json, lalu klik Tambahkan ke draf.
  5. Periksa isi, koreksi fakta, tambahkan media, dan simpan. Publikasikan setelah materi siap dan pengaturan akses sesuai.
Impor menambahkan blok ke akhir isi. Judul terisi dan konten sebelumnya dipertahankan. Jika materi baru hanya memiliki satu paragraf kosong, paragraf itu diganti oleh isi artikel. Impor mengubah draf editor; penyimpanan ke server dilakukan melalui tombol simpan materi.

Materi baru mengikuti pengaturan draf editor. Impor pada materi yang sudah terbit mempertahankan pengaturan visibilitasnya; perubahan akan berlaku saat materi disimpan. Jika perlu meninjau secara privat, gunakan materi draf terpisah.

2. Sebelas jenis blok

Artikel merupakan urutan blok. Setiap blok memiliki id, type, dan objek data. Nama type menggunakan nilai berikut persis, dengan huruf kecil.

Blok Isi data Kegunaan
paragraph text: string Paragraf. Mendukung HTML ringan.
heading text: string; level: 1, 2, atau 3 Judul/subjudul. Gunakan level 2 dan 3 untuk struktur artikel di bawah judul materi.
image fileObjectId, altText; caption opsional; alignment: left/center/right/full (default center) Gambar yang diunggah melalui editor, deskripsi alternatif dan keterangan. Alignment disimpan dalam data; penampil saat ini memakai tata letak gambar standar.
code_snippet code, language; filename opsional; showLineNumbers opsional (default true) Kode dengan pewarnaan sintaks dan tombol salin. Field nomor baris disimpan; penampil saat ini belum menampilkan nomor baris.
math_latex expression: string Rumus LaTeX yang didukung KaTeX, ditampilkan sebagai rumus terpisah.
callout title, text, alertType Catatan dengan tipe NOTE, TIP, IMPORTANT, WARNING, atau CAUTION. Isi mendukung HTML ringan; judul berupa teks biasa.
checklist items: array objek {id, text, checked} Langkah belajar/latihan. Pengguna menandai progresnya sendiri. Teks item berupa teks biasa.
table rows: array baris berisi string sel; header: boolean (default true) Tabel. Baris pertama menjadi judul kolom saat header true. Isi sel berupa teks biasa.
file_attachment fileObjectId, displayName Lampiran yang diunggah melalui editor dan diunduh dengan izin kelas.
embed_media url, title Media dari origin yang diizinkan aplikasi. Tambahkan melalui editor; gunakan URL embed yang sesuai penyedia.
divider {} Garis pemisah antarbagian.

Editor menyediakan penambahan blok, pengurutan dengan seret atau panah, duplikasi, dan penghapusan. Menekan / pada kolom teks yang masih kosong membuka pilihan jenis blok. Gambar dapat diunggah, ditempel, atau diseret ke editor.

3. Tag HTML yang didukung

HTML ringan berlaku pada data.text milik paragraph, heading, dan callout. Tag yang diizinkan: 

p, br, strong, b, em, i, u, s, code, a, mark, span
Tujuan Contoh di kolom teks
Tebal <strong>Istilah penting</strong> atau <b>Istilah</b>
Miring <em>Istilah asing</em> atau <i>Istilah</i>
Garis bawah <u>Teks</u>
Coret <s>Teks lama</s>
Kode dalam kalimat <code>response.ok</code>
Sorot <mark>Perhatikan bagian ini</mark>
Baris baru Baris pertama<br>Baris kedua
Tautan <a href="https://alamat-sumber-asli/" title="Sumber">Baca sumber</a>

Atribut yang diizinkan hanya href dan title. Utamakan tautan HTTPS yang sudah diverifikasi. span dapat mengelompokkan teks, tetapi tidak memberi gaya khusus. p diizinkan oleh pembersih HTML; untuk isi satu blok, utamakan teks inline dan br karena penampil sudah menyediakan elemen paragraf.

Tag judul h1–h6, daftar ul/ol/li, gambar img, dan iframe dibuat melalui jenis blok yang sesuai. script, style, atribut CSS, class, dan event handler tidak didukung di teks artikel.

Format Markdown seperti **tebal**, # Judul, dan tabel dengan pipa tidak otomatis dikonversi. Gunakan HTML ringan untuk teks dan objek blok untuk judul, tabel, kode, serta rumus. Baris baru biasa dalam string paragraf juga tidak menjamin pergantian baris visual; gunakan <br>.

4. Format artikel untuk impor

Objek JSON teratas harus memiliki tepat dua field: title dan blocks. Contoh minimal yang siap diimpor: 

{
  "title": "Memahami Request dan Response",
  "blocks": [
    {
      "id": "blok-01",
      "type": "heading",
      "data": { "text": "Tujuan pembelajaran", "level": 2 }
    },
    {
      "id": "blok-02",
      "type": "paragraph",
      "data": {
        "text": "Membedakan <strong>request</strong> dan <strong>response</strong>."
      }
    },
    {
      "id": "blok-03",
      "type": "callout",
      "data": {
        "title": "Latihan",
        "text": "Jelaskan alur permintaan data dengan contoh sendiri.",
        "alertType": "TIP"
      }
    }
  ]
}

template-artikel.json menyediakan contoh lebih lengkap dengan delapan jenis blok yang dapat diimpor. Ubah konten contoh sesuai topik, sambil mempertahankan nama field dan tipe datanya.

  • Judul: tidak kosong, maksimal 200 karakter. Batas impor adalah 1 MB JSON UTF-8 dan total materi maksimal 300 blok.
  • ID: setiap blok dan item checklist memiliki ID tidak kosong dan unik. ID blok maksimal 100 karakter. Aplikasi membuat ID baru saat impor agar tidak bercampur dengan progres sebelumnya.
  • Teks: field teks blok maksimal 100.000 karakter. Gunakan blok lebih kecil agar materi nyaman dibaca.
  • Checklist: maksimal 200 item. Berikan checked:false; saat impor semua item disiapkan sebagai belum dicentang.
  • Tabel: maksimal 200 baris, 30 sel per baris, 2.000 karakter per sel. Isi setiap baris dengan jumlah kolom yang konsisten.
  • Kode: language maksimal 40 karakter dan filename maksimal 200 karakter. Simpan kode mentah, tanpa tag HTML atau pembatas Markdown.
  • Rumus: simpan ekspresi LaTeX tanpa $ atau $$. Backslash wajib di-escape dalam JSON: {"expression":"\\frac{a}{b}"}.
  • JSON: gunakan kutip ganda. Escape kutip di dalam string sebagai \", baris baru sebagai \n, dan backslash sebagai \\. Angka dan boolean tidak diberi kutip.

5. Gambar, lampiran, dan media

Impor AI menerima paragraph, heading, code_snippet, math_latex, callout, checklist, table, dan divider.

Tambahkan tiga jenis media setelah impor menggunakan editor:

  1. Gambar: pilih blok Gambar, unggah PNG/JPEG/WebP, isi deskripsi alternatif dan keterangan.
  2. Lampiran: klik Sisipkan lampiran pada panel Panduan & artikel AI (atau pilih blok Lampiran berkas), klik Unggah berkas, lalu isi nama tampilan. Lampiran menjadi blok dalam artikel dan dapat dipindahkan di antara paragraf lainnya.
  3. Media embed: pilih blok Media embed, isi judul dan URL embed dari penyedia yang diizinkan.

Lampiran mendukung format seperti PDF, DOCX, PPTX, ZIP, CSV, dan teks, maksimal 50 MB per berkas. Peserta dapat mengunduh lampiran setelah materi dan Section dapat diakses. Untuk menyajikan PDF sebagai modul dengan penampil halaman, gunakan jenis materi Modul PDF.

fileObjectId dihasilkan oleh aplikasi sesudah unggah. AI tidak dapat membuat ID berkas yang valid. Aplikasi memeriksa kepemilikan kelas, jenis berkas, dan kesiapan berkas saat materi disimpan. Embed juga harus melewati izin origin yang dikonfigurasi pengelola aplikasi.

6. Struktur artikel yang disarankan

Mulai dari tujuan dan pengetahuan awal, lalu gunakan subjudul bertahap, paragraf singkat, contoh yang relevan, latihan/refleksi, dan rangkuman. Tabel membantu perbandingan; callout menandai poin penting. Checklist cocok untuk langkah belajar yang ingin ditandai mahasiswa.

Prompt AI sebaiknya menyebutkan topik, mata kuliah, semester atau tingkat kemampuan, kompetensi yang dituju, panjang artikel, gaya penulisan, sumber yang diberikan, dan kebutuhan seperti kode atau rumus. Berikan bahan sumber agar contoh dan penjelasan sesuai materi kelas.

7. Jika impor gagal

Pesan atau kondisi Perbaikan
JSON tidak valid Hapus pembatas ```json, pengantar AI, komentar, dan koma terakhir. Periksa kutip, escape, serta pasangan kurung.
Format pada blocks.2.data.level Angka setelah blocks adalah indeks, dimulai dari 0. Periksa field level pada blok ketiga; gunakan angka 1–3.
ID harus terisi dan unik Gunakan ID berbeda untuk setiap blok dan item checklist, misalnya blok-01 dan latihan-01.
Tambahkan media melalui editor Hapus blok image/file_attachment/embed_media dari JSON impor, lalu tambahkan media melalui menu blok.
Lebih dari 300 blok atau 1 MB Minta AI meringkas, bagi materi ke beberapa artikel, atau impor ke materi baru.
HTML tidak tampil seperti harapan Gunakan hanya tag dan atribut pada bagian 3. Teks checklist, tabel dan judul callout tidak menampilkan HTML.

8. Pemeriksaan sebelum publikasi

Periksa akurasi isi dan sumber, jalankan contoh kode pada lingkungan latihan, cek notasi rumus, pastikan gambar dan lampiran bisa dibuka, serta baca tampilan artikel sebagai mahasiswa. Hindari memasukkan data pribadi ke prompt. Dosen tetap meninjau hasil AI sebelum menjadikannya bahan belajar.
